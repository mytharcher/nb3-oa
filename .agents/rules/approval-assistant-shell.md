# Approval assistant shell composition

The application mounts ApprovalAssistantProvider once around the business shell to preserve the read-only Agent conversation across routes. HeaderActions opens its right drawer. Keep the existing navigation, theme, language and sign-out behavior. Contracts supply only a record identifier; tools recheck current authorization. Opinion drafts live only in memory, are keyed by signed-in user and contract, and require an explicit insert action in the existing approval form. They never submit a decision.
